# 大虎图像

[English](README.en.md)

用 PySide6 做的桌面工具，用来处理图片和转换 PDF。当前功能是把多张图片合成一个 PDF，并用分辨率和 JPEG 质量控制文件大小。

需要 Python 3.12 或更高版本。依赖写在 `requirements.txt`：PySide6、Pillow、img2pdf、pillow-heif。

## 运行

项目里已经有 `venv`。在项目根目录执行：

```bash
./venv/bin/pip install -r requirements.txt
./venv/bin/python main.py
```

## 图片转 PDF

把图片拖进窗口，或使用「添加图片」「添加文件夹」。文件夹只读取当前这一层。页面顺序可以拖动，也可以用上移、下移调整。选好参数后点「生成 PDF」。

支持 PNG、JPG、WEBP、BMP、TIFF、GIF、HEIC、HEIF。透明背景会铺成白色，图片会按拍摄方向转正，动图只用第一帧。小图不会被放大。

右侧可以调节：

- 页面：A4、Letter，或原始比例。固定纸张可以设置页边距，横图可以自动换成横向页面。
- 压缩：手动调节，或按目标体积。预设有小文件、标准、高清、印刷，也可以自定义。
- 手动调节时，固定纸张用 DPI，原始比例用最长边，再加 JPEG 质量。
- 按目标体积时，上面的分辨率和质量是上限。程序会在这个上限内寻找能放进目标的设置。

快捷键：打开文件用 Cmd/Ctrl+O，保存用 Cmd/Ctrl+S。在图片列表上按 Delete 或 Backspace 可以移除选中的图片。

## 体积是怎么变小的

PDF 的大小基本就是里面每张 JPEG 的大小。每张图只压缩一次：

1. **先降分辨率。** 选 A4 或 Letter 时，像素上限是「去掉页边距后的纸张尺寸 × DPI」。选原始比例时，只限制最长边。图片按比例缩小。边长减半，像素大约剩四分之一，这是控制体积的主要办法。
2. **再压成 JPEG。** 质量越高越清晰。90 及以上保留完整色彩，适合印刷；75 到 89 略微合并色彩；更低时使用更强的色彩抽样，文件更小。
3. 这些 JPEG 原样放进 PDF，不会再压一次。

「按目标体积」会先在分辨率上限内寻找能放进目标的最高 JPEG 质量。最低质量仍然放不下，就继续缩小分辨率，直到放进目标，或者到达可读下限（质量 35、分辨率约为上限的 40%）。到了下限仍然大于目标时，程序会写出当前能得到的最小文件，并给出提示。

界面里的「查看压缩说明」有同样的说明。

## 代码怎么分层

- `shared/domain`：读图、缩小、JPEG 编码、整理文件名。这一层不依赖界面。
- `shared/presentation`：多个功能共用的窗口、样式、图片队列和后台任务。
- `features/<功能名>`：这项功能自己的参数、处理流程和页面。当前是 `features/image_to_pdf`。
- `main.py`：注册功能并启动。
- `version.py`：版本号。

以后加功能时，新增一个 `features` 子包，在 `main.py` 里注册，并把包名写进 `pyproject.toml`。已有功能不用改。
